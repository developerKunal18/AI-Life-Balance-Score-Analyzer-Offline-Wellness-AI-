# 🧠 AI Life Balance Score Analyzer 

## 💡 Overview
The **AI Life Balance Score Analyzer** is an offline Python application that evaluates your **overall life balance** by analyzing multiple daily factors such as work, sleep, exercise, learning, and stress.

It generates a **Life Balance Score (0–100)** and provides AI-style insights to help improve wellness, productivity, and long-term sustainability.

This project is inspired by **wellness dashboards, HR analytics tools, and life-coaching AI systems**.

---

## 🚀 Features

### ⚖️ Holistic Life Analysis
Analyzes:
- Work hours
- Sleep duration
- Exercise activity
- Learning time
- Stress level

### 📊 Life Balance Scoring
- Calculates a comprehensive **Life Balance Score**
- Classifies balance into:
  - 🌟 Excellent
  - 🙂 Balanced
  - ⚠️ Imbalanced
  - 🚨 Critical

### 🧭 AI Lifestyle Suggestions
- Provides actionable recommendations to:
  - Improve sleep
  - Reduce stress
  - Avoid overwork
  - Increase physical activity
  - Encourage learning

### 🌐 Fully Offline
- No APIs
- No internet required
- Runs locally in the terminal
